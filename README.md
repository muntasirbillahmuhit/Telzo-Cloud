# Telzo Cloud

Telegram-powered personal cloud storage for photos, files, and folders.

## Features
- **Telegram Cloud Sync**: Connect to Telegram to leverage unlimited private storage channels and Saved Messages.
- **Photos View & Starred**: Fast photo browsing with 1:1 gallery previews and quick starring.
- **Folder Management**: Organize documents and assets into private Telegram storage groups.
- **Tagging & Filtering**: Quick tag categorization (Work, Personal, Design, Important) with real-time counters.
- **Appearance**: Seamless switching between System, Light, and Dark themes.
- **Trash & Recovery**: Safe file deletion and restoration before permanent removal.
- **Local & Offline Caching**: Browser-first persistence with automatic state synchronization.
